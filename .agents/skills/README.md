# Workspace Skills

Thư mục này dùng để chứa các **Skills** áp dụng cho dự án hiện tại.

## Cách thêm skill mới:
1. Tạo một thư mục con với tên skill (ví dụ: `my-skill/`).
2. Bên trong thư mục đó, tạo tệp `SKILL.md` với định dạng:

```markdown
---
name: my-skill
description: >-
  Mô tả rõ ràng chức năng và khi nào agent nên kích hoạt skill này.
---

# My Skill

Nội dung hướng dẫn thực thi...
```
